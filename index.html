RetailPulse — Demand Forecasting & Operations Analytics

Aug 2026
6.6% MAPE · 22.9% better than baseline

Forecasts daily order demand across three locations, validates the model against naive baselines with rolling backtests, and converts the forecast into a staffing plan. Built to answer the question an operations manager actually asks: how many people do I need on the floor next Saturday, and how confident are we?

  • Holt-Winters model with additive trend and weekly seasonality, scoring 6.6% MAPE — a 22.9% error reduction versus a seasonal-naive baseline.
  • Rolling-origin backtesting across four folds, so no fold is ever scored on data the model trained on.
  • Staffing translation converting the point forecast and its 95% bounds into daily headcount, with adjustable throughput assumptions.
  • Streamlit dashboard for KPIs and demand patterns — surfaced that the smallest location is the fastest growing at +14.7% YoY.

AskData — Natural-Language Analytics Copilot

Aug 2026
21-case security suite · 12-case benchmark

Ask a business question in plain English; get back validated SQL, the result table, a chart, and a written interpretation. The interesting engineering isn't the model call — it's the layer around it. Generated SQL is treated as untrusted input and never reaches the database unvalidated.

  • Claude API pipeline translating plain-English questions into SQL over a four-table database, then narrating the results.
  • Guardrail layer whitelisting SELECT statements, blocking stacked queries and comment-based evasion, and executing read-only under a row cap and timeout.
  • 21-case security suite covering destructive statements, injection attempts, and filesystem functions — while confirming legitimate queries still pass.
  • Execution-based benchmark of 12 questions graded easy/medium/hard, scoring SQL on result-set correctness rather than string matching.
